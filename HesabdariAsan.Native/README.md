# حسابداری آسان Native v4 — Phase 4

این شاخه بازنویسی واقعی Windows Desktop است: **C# + .NET 8 + WPF + SQLite**. رابط اصلی HTML/CSS/JavaScript/WebView ندارد و نسخه v3.4 را دست‌نخورده نگه می‌دارد.

## موارد تکمیل‌شده تا این فاز

- Dashboard، فروش، کالاها، مشتریان/شرکت‌ها، خرید، هزینه‌ها، انبار، گزارش، Audit و تنظیمات به‌صورت WPF Native
- Pagination دیتابیس با پیش‌فرض 10 و انتخاب 20/50
- فروش Transactional: فاکتور + اقلام + موجودی + کاردکس + قرض در یک تراکنش
- **خرید و ورود کالا**: انتخاب کالا و شرکت، خرید نقدی/نسیه، افزایش موجودی، به‌روزرسانی آخرین قیمت خرید، ثبت کاردکس و افزایش قرض شرکت در خرید نسیه
- تاریخچه خریدها با Pagination واقعی دیتابیس
- **ویرایش امن فاکتور**: اصلاح تعداد، قیمت فروش، حذف ردیف و تخفیف؛ برگشت موجودی قدیم و اعمال موجودی جدید داخل یک Transaction
- **ابطال فاکتور بدون حذف تاریخچه**: فاکتور به حالت CANCELLED می‌رود، موجودی برمی‌گردد، قرض مشتری برای فاکتور نسیه اصلاح می‌شود و Revision/Audit باقی می‌ماند
- برای حفاظت حساب، اگر پس از فاکتور نسیه پرداخت قرض ثبت شده باشد، ویرایش/ابطال مستقیم آن فاکتور مسدود می‌شود تا مانده مشتری خراب نشود
- فاکتورهای باطل‌شده از فروش و سود نمودارها/داشبورد حذف می‌شوند ولی در گزارش و Audit باقی می‌مانند
- چاپ فاکتور باطل‌شده با علامت واضح «فاکتور باطل شده»
- Invoice Revision از زمان ایجاد فاکتور و قبل از ویرایش/ابطال
- Audit Native برای فروش، ویرایش/ابطال فاکتور، کالا، مشتری/شرکت، پرداخت قرض، هزینه، خرید، تنظیمات، Restore و مهاجرت v3.4
- جلوگیری از حذف مشتری/شرکتی که مانده قرض یا سابقه مالی دارد
- جلوگیری از ثبت بارکد تکراری روی دو کالای فعال
- Raw Input برای بارکدخوان USB/HID در زمانی که پنجره برنامه فعال است
- چاپ Native فاکتور 80mm از طریق Windows Print Driver؛ مناسب XPrinter دارای درایور Windows
- انتخاب پرینتر، چاپ خودکار اختیاری پس از فروش و چاپ مجدد فاکتور
- هیچ فرمان Auto Cut در برنامه وجود ندارد
- Backup آنلاین SQLite با `BackupDatabase` و بررسی `PRAGMA quick_check`
- Restore با Backup ایمنی خودکار قبل از جایگزینی دیتابیس
- مهاجرت دیتای v3.4 به v4: کالا، بارکد، مشتری، شرکت، قرض، فاکتور، اقلام، هزینه، خرید، دریافت مشتری، پرداخت شرکت، کاردکس، دوره مالی، Audit و Revision
- انتقال هویت فروشگاه، مدیر، تم، اندازه متن، پرینتر و عکس‌های Base64 نسخه v3.4
- حفظ `legacy_id_map` برای ردیابی شناسه‌های قدیمی پس از مهاجرت
- اصلاح ساعات کاری در برابر Sleep/Resume و جهش بزرگ ساعت سیستم
- Log خطاهای غیرمنتظره در `%APPDATA%\HesabdariAsan\Logs`
- بررسی سلامت دیتابیس در Startup و از داخل تنظیمات
- GitHub Actions: Build واقعی Windows x64 + ساخت `Hesabdari-Asan-v4-Setup.exe` با Inno Setup
- Installer از نوع Current User است و Uninstall عمداً دیتابیس `%APPDATA%` را حذف نمی‌کند

## وضعیت Build

در محیط توسعه این گفتگو .NET/Windows runtime موجود نیست؛ بنابراین Compile واقعی WPF در این محیط اجرا نشده است. فایل‌های XAML از نظر XML، ساختار کلاس‌ها، Balance کدهای C# و تست دیتابیس بررسی شده‌اند. Workflow ویندوز در GitHub ابتدا `dotnet build` را اجرا می‌کند و فقط در صورت موفقیت، Publish و Installer را می‌سازد.

این نسخه هنوز **Production نهایی** نیست؛ Phase 4 یک checkpoint جدی برای منطق مالی و تاریخچه است. مرحله بعدی Production Hardening شامل Build واقعی Windows، تست روی XPrinter/Barcode واقعی، بهبود جزئی UI و تست نصب/آپدیت روی دیتای واقعی خواهد بود.
